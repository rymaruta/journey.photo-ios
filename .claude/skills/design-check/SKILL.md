# デザインの確かめ

CLAUDE.md の「デザインするときは必ずデザインの板を読む」を守るための手順。

## 1. 板を読む

Artifact ツールの `action: "read"` で https://claude.ai/artifact/XN38zw2BHegEU7SuxgKrr6 を読み、
`path` に `project/DesignSystem.dc.html` と、変える画面の板（files の一覧から探す）。
読めなければ**作らずに止めて報告**する。

## 2. 決まり（板が変わっていたら板が正。ただし CLAUDE.md の owner の好みが優先）

- 写真が主役。UI は黒と白。真鍮 `#C9A66B` は**黒い地の上だけ**。写真の上は白だけ。
- owner の好み: デザインの箇所は白より真鍮（合図・リンク・選んでいるもの・件数バッジなど）。
  写真の無い画面の主ボタンは真鍮の塗り（`accentFill`）＋墨の字。写真のある画面の主ボタンは白。
- 危険の色は `WebTheme.danger`。系統の赤を画面の行に出さない。
- 本文 12pt 以上（眉ラベルだけ 11）。押せるものは 44pt（見た目が小さくても当たりは 44）。
- 見出しは明朝、本文はシステム、数字は SF の等幅数字（`JPFont.mono`）。
- 色だけで状態を伝えない（形・読み上げでも伝える）。英語も `L("日本語", "English")`。

## 3. 見て確かめる

`/mac-check` で画面写真（ScreenshotTests）を撮り、Read で見る。
新しい画面には ScreenshotTests に1枚足す（出なければ撮らずに抜ける書き方）。
owner に見せるときは、モックか実際のアプリの画面かをはっきり書く。
