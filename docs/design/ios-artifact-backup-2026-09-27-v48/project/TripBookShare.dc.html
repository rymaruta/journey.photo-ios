静的サイトなので、iOS が URL を送った直後はまだページが無い。この1行は URL が /users/<id>/trips/<slug> の形のときだけ 404 に足す（打ち間違いの URL には出さない）。

URL の決め方

/users/<id>/trips/<slug>。slug は「開始日-最頻撮影地」（例 2026-09-12-kanazawa）の決定的な値。iOS と Web が同じ規則で導くので、どちらかがずれると 404 になる。

ゲストにログインを求めない。読むだけなら登録なし。数字は「3日間・12枚」の自分の事実だけで、閲覧数・いいね数・比較は出さない。全体公開の写真だけで組む。

「たどった場所」は座標が2地点以上のときだけ。無ければ枠ごと出さない。
