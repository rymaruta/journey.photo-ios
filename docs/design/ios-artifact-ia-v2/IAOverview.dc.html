TABS

CHANGE
1. 旅の道具は「旅の記録」だけ
アルバム・プラン・すれちがい・トランク・キャンパーの正規入口を Trips に集約。メニュー／設定からは削る。
2. 先頭チップ＋一冊の棚
道具は画面上端の短いチップ（すぐ開く）。棚は大きいまま下に続ける。詳細リストも下に残す。
3. 投稿は主3＋副2
写真 / ストーリー / 旅から。カメラ・構図は「写真のほかの撮り方」。
4. メニューは案内に戻す
マップへ移る・いいね・保存・アカウント。旅の道具は載せない。
KEEP
  • 下タブ 5（ホーム／探す／投稿／マップ／マイページ）
  • お知らせは見出しのベル（タブにしない）
  • ストーリーはホームの輪＋投稿シート
  • マイページ内タブ: 投稿／旅の記録／行きたい場所／保存
