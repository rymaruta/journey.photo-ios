## 利用者の目線（要約）

△だったところを板で潰し、どれも◎に寄せた。

| 弱点だった点 | 手当て |
|---|---|
| キャンパー等の初見 | `Trips` 先頭に道具チップ（すぐ開く） |
| 共同アルバム | チップ先頭＋一覧でも先頭 |
| 行きたい場所↔プラン | `WantedPlaces` 先頭に「旅行プランを開く」 |
| マイページ上段が長い | 上段の一冊棚を外し、旅タブ → `Trips` |

詳細は `PersonaLens.dc.html`。

## 変えないこと

- 下タブ: ホーム / 探す / 投稿 / マップ / マイページ
- お知らせは見出しのベル
- ストーリーはホームの輪＋投稿シート

## 見方

1. まず `IAOverview.dc.html`
2. つづいて `Trips.dc.html` → `SiteMenu.dc.html` → `PostSheet.dc.html`
3. 画像の `/_blob/...` はアーティファクト内でのみ解ける（この写しでは出ない）

## アプリへの落とし方（採用後）

1. 正規入口をマイページ「旅の記録」に寄せる（メニュー／設定の二重入口を外す）
2. 投稿シートを主3＋副2に寄せる
3. owner の OK のあと実装 PR → TestFlight
