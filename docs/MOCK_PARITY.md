# モック10枚と実装の突き合わせ（2026-09-21）

owner から届いた「最終版」10枚に対して、**いま出来ているもの・これから作るもの・
作れないもの**を1つずつ。作れないものは**理由と、作るなら何が要るか**まで書く。

凡例: ✅ できている / 🔨 これから / ⛔ いまのサーバーでは作れない

## いまの優先順（作る順）

1. **スポット詳細をモック5の構成へ**（概要・アクション行・近くのスポット・ページャ）
2. **マップの検索・リスト・このエリアを検索**
3. **通知の時間グループ化・フォローバック・空の状態**
4. **今日のミッション**（端末側で完結する形）
5. **行きたい場所**（端末に保存・スポット詳細とマイページの両方から）
6. ストーリーの進行バーとメニュー、写真詳細のタブ切り替え

残る ⛔ は**サーバー側の変更が先**。アプリだけで出すと、押しても効かない
切り替えや、数えていない数字を置くことになる。

外せたもの（サーバーを足して解いた）:

| もとの ⛔ | 何を足したか |
|---|---|
| 認証バッジ | `userProfile.ts` の `verified`。**本人には書かせない**（`apply` の白名簿に入れていない） |
| ハイライト | 既にある `TripBook` の上に丸い行を重ねた（新しい入れ物は作っていない） |
| 複数枚投稿 | `groupId`。**行は1枚ずつのまま**なので個別ページもサイトマップも減らない |
| 色から探す | `dominantColor` をアプリからも送るようにした（Web は前から送っていた） |
| 親しい友達 | `closeFriends.ts`（`GET`/`PUT`/`DELETE /user/close-friends`） |
| 公開範囲（写真） | `RESTRICTED_FEED_KEY` と `GET /feed/restricted`。**索引は足していない**——既にある `publicFeed-createdAt-index` の別の仕切りを使う |

まだ残っている ⛔: BGMカード（プロフィールの曲）・スポットの評価/口コミ・
距離の計測・保存/メンションの通知・運営からのお知らせ・シェアシートの
各社スキーム・ストーリーのスワイプ。
